# Wind Tunnel Upgrade: motorized 6-component sting balance

## ▶ View the website: [rujones92.github.io/Wind-Tunnel-Upgrade](https://rujones92.github.io/Wind-Tunnel-Upgrade/)

This repository hosts the design package for a motorized sting force balance for a university low-speed wind
tunnel (test section 26.25 × 11.25 × 30 in, 70-100 mph). The tunnel tests 3D-printed aircraft models. A one-piece
aluminium strain-gauge balance measures all six force and moment components. Stepper motors roll (±90°), pitch
(-6° to +20°) and yaw (±15°) the model, controlled from a Raspberry Pi station.

Open the link above to browse the package. GitHub's file view shows `index.html` as source code, so use the
website link instead. The website includes:

- **Overview, Requirements, Balance, Models & pod, Motion, Electronics & control, Calibration:** the design and how
  it works, with CAD renders and wiring diagrams
- **Drawings:** 35 GD&T sheets (assemblies with parts lists and every machined part), as PDF
- **Machining cost:** a real JLCCNC quote, the expected final order and an ordering checklist
- **Implementation plan, Design history, References:** phases, budget, risks, literature, and downloads of all STEP
  files and scripts

The drawings are REV A and AI-assisted. They have not yet been checked or approved for manufacture. Yaw-carriage
sheets (5xx) are preliminary until the tunnel's downstream bay is measured.
